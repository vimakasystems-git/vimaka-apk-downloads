# exploreSAMPA.com — APK Beta Android

**Beta para testes e homologação. NÃO é um release assinado para produção nem um APK aprovado pela Google Play.**

| Campo | Valor |
|---|---|
| Nome | exploreSAMPA.com |
| Versão | 0.9.0-beta (debug) |
| Pacote Android | `br.com.vimaka.explorasampa` |
| Android mínimo | API 24 (Android 7.0) |
| Target Android | API 36 |
| Assinatura | Android Debug / v2 (verificação `apksigner` aprovada) |
| Permissões | INTERNET (além de permissão automática de receptor de biblioteca Android) |
| Fonte | https://github.com/vimakasystems-git/explorasampa-base44 |

Este APK foi compilado a partir do código do exploreSAMPA.com com Capacitor 8 e Gradle. O frontend e o catálogo de lugares estão disponíveis para testes. Login, avaliações e funções que dependem do Base44 ainda exigem a origem publicada do backend configurada.

**Avisos:** versões beta podem usar chaves de debug diferentes, exigindo desinstalação da versão anterior antes de instalar uma atualização. Não use este APK para distribuir uma versão final da Vimaka ou publicar na Google Play. A versão final requer chave de assinatura persistente em armazenamento seguro e testes em dispositivos reais.

Confira a integridade usando `SHA256SUMS.txt`. Não envie informações sigilosas durante a homologação.
