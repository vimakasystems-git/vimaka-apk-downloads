## Versioning and release assets

Each verified release includes a production-signed APK, release notes, minimum Android version and SHA-256 checksum.

Recommended example for the first Tvillingarnas release (not yet available):
- Tag: `tvillingarnas-maleri-v1.0.0`
- Asset: `tvillingarnas-maleri-v1.0.0.apk`
- Checksum: `SHA256SUMS.txt`

See [RELEASING.md](RELEASING.md) for the release procedure. Do not publish source credentials, signing keys or debug APKs as production packages.

The Tvillingarnas website can enable a GitHub Releases APK URL through Cloudflare variable `APK_RELEASE_URL`, but only once the actual public, signed APK exists and is verified.
